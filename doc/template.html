Quick start Install & keep updated Build your own

  • Nothing to install

    Nix fetches the agent you pick; arguments after -- go straight to it.

  • Always current

    Harnesses follow upstream daily, and a build lands only once the Linux/macOS builds and NixOS VM tests pass. Install it and your machine follows too, four times a day, from the binary cache, never compiling.

  • Write once

    One Agent Plugins directory works in every harness; the per-harness translation is done for you.

  • Composes with your setup

    Your own plugins, settings, credentials, and sessions stay in place.

  • Make it yours

    nix flake init -t github:juspay/agent-distro starts a distribution with your plugins and, optionally, your LiteLLM gateway.
